# Hidden Nepal

**Hidden Nepal** is an atmospheric 3D exploration and adventure game prototype set in a fictional Nepalese village ("Sundari Gaun").

## Features (Vertical Slice Plan)
- 🏔️ Mountain Trail & Village Exploration (Sundari Gaun)
- 🏃 3D Third-Person Player Controller (Move, Run, Jump, Camera Control)
- 💬 NPC & Dialogue System
- 📜 Quest & Discovery System
- 📸 In-Game Photography & Journal
- 💾 Save & Load System

## Development Stack
- **Engine**: Unity 6 LTS (`6000.6.2f1`)
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Input System**: Unity New Input System
- **Language**: C#
